## 1. Диагноз «что некрасиво» (12 пунктов, file:line по текущему коду)

1. **Подписи пилюль по жёстким координатам**: `cy=h/2−6` и `h/2+11` при канве 44px, запас 0px —
   при крупном шрифте/DPI подписи пересекаются и выталкиваются (D1, main.py:526–531).
2. **Двухвариантные пилюли растянуты с дырой**: `columnconfigure(weight=1)` (main.py:470) +
   `pack fill="x", expand=True` (main.py:1593, 1600) — «60/120 FPS» и «Обычное/Аниме» с пустотой
   посередине (D4).
3. **Невыбранная пилюля со светлой крышкой**: lift `_mix(top,"#ffffff",0.16)` (main.py:492),
   gloss 0.16 (main.py:516–517) — читается как «кривое выделение» (D3).
4. **Switch вплотную к метке «Плавность»** — pack без padx (main.py:1586–1588) (D3).
5. **Ось меток плавает**: `width=11` в символах (main.py:1582, 1676), на пропорциональном
   шрифте ±4px; при узкой карточке клиппится «Кодиров…» (D2).
6. **Спиннер pack+pack_forget флэш** (main.py:1756–1757): слот не зарезервирован, прогресс и
   проценты сдвигаются при появлении спиннера (D5).
7. **Пустой список = мёртвый прямоугольник** — Listbox без подсказки (D6, main.py:1498–1503).
8. **Пустой журнал = голое чёрное поле** — Text без заглушки (D7, main.py:1793–1801).
9. **Рваный вертикальный ритм**: pady (2,0)/(3,0)/(5,2)/(6,0)/(3,4)/(8,2), padx 12 vs 13
   (main.py:1541, 1560, 1580, 1632, 1648, 1675–1682) (D8).
10. **Три несвязанных зазора**: внешние 18 (main.py:1344) / межколоночный 12 (main.py:1378) /
    карточка→журнал 10 (main.py:1405).
11. **Бейдж версии не соосен**: (−18, 44) против оси текста (y=20/47) (main.py:1364–1367, 1446).
12. **Двоится заголовок**: тень с офсетом 2px (main.py:1351–1358), подзаголовок x=24 против
    заголовка x=22 (main.py:1359–1363).

### D1 — вертикаль по метрикам шрифта (вместо констант)

1. `PillChoice.__init__`: `self._font_big = tkfont.Font(size=11, weight="bold")`,
   `self._font_small = tkfont.Font(size=8)`; `tl = big.metrics("linespace")`,
   `cl = small.metrics("linespace")`; есть подпись → `self.h = max(44, tl + cl + 12)`,
   нет → прежние 44/28.
2. `_redraw` (main.py:526–531): block = tl + (cl + 2, если подпись);
   `top = max(2, (h − block) // 2)`; заголовок `create_text(w/2, top, anchor="n")` + тень
   (w/2, top+1.5); подпись `create_text(w/2, top + tl + 2, anchor="n")`.
   Контроль на scaling 1.15: tl≈14, cl≈10 → заголовок с y=9, подпись с y=25, нижний зазор ≈9px.
3. Fallback ширины в `_redraw` (main.py:499–501): вместо `w=140` → `int(canv.cget("width"))`.

### D4 — ширина

- `len(options) <= 2` (FPS, «Тип видео»): БЕЗ `columnconfigure(weight=1)`; ширина пилюли
  `clamp(96, 150, font_small.measure(заголовок) + 30)`; pack без expand/fill (main.py:1593, 1600).
- `len(options) >= 3`: растяжение по карточке сохраняется как сейчас.
- Пресетные big-пилюли: min 110 / max 220, grid-растяжение сохраняется.

## 10. Критерии приёмки

- (а) 985×789 и 1280×900: нет перекрытий/клиппинга; подписи пресет-пилюль внутри канвы;
  заглушки соответствуют состоянию.

- (в) Resize 960..1440 без артефактов; wraplength-адаптация работает; журнал ≥120px при 780.
- (г) `python -m py_compile main.py` exit 0 на каждом шаге.
- (д) Только stdlib; новых импортов нет.
- (е) Полоса прогресса при старте/останове не сдвигается более чем на 1px.
- (ж) Drag&drop: 3 файла (кириллица+пробелы) добавляются, счётчик с флашом; невалидные —
  сообщение в журнале (main.py:1968), заглушка возвращается.
- Крайние случаи: узкая правая колонка @960 — пресет-пилюли ≥110px; длинное имя файла —
  скроллбар жив; scaling 1.33/2.0 — подписи и метки целы; `_fit_panels` после вставок —
  высоты карточек выросли не более чем на 6px суммарно.
