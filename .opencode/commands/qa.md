---
description: Полный прогон тестов с разбором падений по порядку
---

Запусти суб-агента `qa-runner`: сначала `python -m py_compile main.py engine.py`, затем полный прогон `python -m unittest discover tests -v`. По каждому падению: классификация (устал тест / регрессия / среда), предпринятое действие и итоговая сводка «зелёных / упавших / переданных».
