---
description: Полный прогон тестов с разбором падений по порядку
---

Запусти суб-агента `qa-runner`: сначала проверка компиляции `dotnet build` по решению (0 ошибок), затем полный прогон xUnit `dotnet test --verbosity normal`. По каждому падению: классификация (устал тест / регрессия / среда), предпринятое действие и итоговая сводка «зелёных / упавших / переданных». Реальное видео и запуск окна — не запускать: только юнит-уровень.
