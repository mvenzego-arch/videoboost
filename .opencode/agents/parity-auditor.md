что умело v2, не потеряно в v3».

`git show legacy-python:engine.py`; git в `C:\Program Files\Git\cmd\git.exe`).

   журнал, отмена, открыть папку, скачивание инструментов, HDR-детект, счётчик
   файлов, окрашенные логи, пресет-	desc и станные перес решений.
2. Сверяешь с кодом v3 (`src/`) и спекой ux-designer — таблица
   «фича → статус: в v3 / мигрировано / MISSING / осознанно изменено (почему)».
3. Сверяешь поведение, а не только наличие: «отмена держит temp чистым», «дубликаты
   файлов не звгоняются», «ошибка видна в журнале» — поведенческие пункты с
   критерием «как проверить».
4. Отдельный блок: pref-ключи (`ui_settings.json` legacy-ключи как чек-лист из спеки)

   (engine-dev) / UI-часть (ui-dev), разделяющие).
6. Финал: паритет %, список MISSING, вердикт PARITY OK / GAPS N. По-русски.

(Legacy-CSS-шло-на-canvas!!! об откатах вопросы к владельцу). Двигается только
справедливая миграция.
