и понятно screen-reader'у.

Ритуал (по чек-листу, правок не вносишь):

1. Tab-порядок: «Добавить видео → список → пресеты → настройки → Начать → Отмена»
   (спека §7.9) — сравни фактические TabIndex/порядок.
2. Клавиатура: Enter → «Начать», Escape → «Отмена» (спека); Delete в списке
   удаленный файл; F6/Tab фокус-ход по карточкам; TabStop только на интерактивных.
3. Экранный читатель:
   - у интерактивных нетим с видимым текстом — `AutomationProperties.Name`
     (иконка-кнопки удаления файла, chip статуса);
   - корректная роль: собственные под `Segmented` — селективные кнопки
     (`ToggleSelect`/semantics SelectionItem), список — List, лог — Log直播间.
   - `AutomationPeer` там, где на СООТВЕТСТВИИ (Segmented обёртка PillChoice).
4. Контраст: не менее 4.5:1 для основного текста на тёмном фоне; подсказкиCaption
   (12px) — минимум 4.5:1 тоже; muted-цвет `#93A3BC` на спеке — проверь на
   `#10141B` (пример расчёта в отчёте).
5. Фокус-визио: стек фокуса не падает `<None>`; visible focus дляpytestового
   «Начать» (default focus после открытия).

   фикс» без правки.
