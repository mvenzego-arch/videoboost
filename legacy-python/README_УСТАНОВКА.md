# Video Boost v1.2 — улучшение качества и плавности видео

Простая программа для Windows: берёт обычное видео, делает его **чётче**
(нейросетевой апскейл до **4K/8K**) и **плавнее** (интерполяция до **60/120 FPS**),
а звук сохраняет без перекодирования.

Оптимизировано под **AMD Radeon RX 570 4 ГБ + Ryzen 5 2600 + 16 ГБ RAM**.
Работает через Vulkan, поэтому видеокарта используется и для апскейла, и для кодирования
(AMD AMF). Если AMF недоступен — автоматически переключается на CPU-кодировщик libx264.

Интерфейс — **тёмная тема «жидкое стекло»**: полупрозрачные стеклянные карточки
с мягкими бликами и анимациями, пилюли-пресеты, тумблеры, собственная полоса
прогресса с бегущим огоньком и подсказки у каждого параметра. Все действия
дублируются в журнал — панель внизу окна и текстовый файл `logs\`.

---

## Быстрый старт

1. Распакуйте папку `VideoBoost` в любое место (например, `E:\прога\VideoBoost`).
   Кириллица и пробелы в пути допустимы.
2. Запустите **`VideoBoost.exe`** двойным кликом — Python не нужен.
   (Альтернатива — `start.bat`: запуск через установленный Python.)
3. При первом запуске программа сама скачает инструменты (~700 МБ, 5–15 минут).
4. Добавьте видео: **перетащите файлы мышкой прямо в окно программы**
   или нажмите **«Добавить видео…»** (можно сразу несколько файлов).
5. Выберите пресет и нажмите **«Начать обработку»**.
6. Готовый файл появится **рядом с исходным**: `имя_файла_UPSCALED.mp4`.

> Если Windows покажет «Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».
> Это стандартное предупреждение для новых `.exe`/`.bat`-файлов, которых «ещё никто не запускал».

---

## Перетаскивание видео в окно

Файлы можно просто **зажать мышкой в проводнике и бросить в окно программы** —
они добавятся в список автоматически.

- Поддерживаются: `.mp4` `.mkv` `.mov` `.avi` `.webm` `.m4v` `.ts` `.wmv` `.flv`
  `.mpg` `.mpeg` `.3gp`;
- можно кинуть **сразу несколько** и даже папку-микс — файлы с расширением не из
  списка (например, картинки) программа молча пропустит;
- повторы не дублируются: одно и то же видео не попадёт в список дважды;
- во время обработки перетаскивание отключено (список фиксируется до конца работы);
- работает без установки каких-либо библиотек — только средства Windows.

## Что скачивается при первом запуске

| Инструмент | Размер | Назначение |
|---|---|---|
| FFmpeg | ~195 МБ | извлечение кадров, сборка результата |
| Real-ESRGAN ncnn Vulkan | ~46 МБ | нейросетевой апскейл x2–x4 |
| RIFE ncnn Vulkan | ~432 МБ | интерполяция кадров до 60/120 FPS |

Всё складывается в папку **`tools`** рядом с программой. В систему ничего не устанавливается.
Прогресс скачивания виден в журнале и на полосе прогресса.

Если интернет отключился — программа повторит попытку. Если ссылка на инструмент устарела,
будет понятное сообщение и ссылки для ручного скачивания (см. раздел ниже).

## Пресеты

| Пресет | Апскейл | Плавность | Кодировщик | Tile | Для чего |
|---|---|---|---|---|---|
| **Быстро** | **x2** (1080p → 4K), лёгкая модель | нет | H.264 (AMF) | 256 | Проверить результат, слабый ПК, длинные видео |
| **Баланс** | **x2** (1080p → 4K), лёгкая модель | до 60 FPS | H.265 (AMF) | 384 | Оптимальный вариант для большинства |
| **Максимально** | **x4** (1080p → **8K**), тяжёлая модель | до 60 FPS | H.265 (AMF), качество «Макс» | 512 | Лучшее качество, но очень медленно |

Например: видео 1080p → в «Быстро» и «Баланс» получится **4K (3840×2160)**,
в «Максимально» — **8K (7680×4320)**.

Лёгкая модель `realesr-animevideov3` даёт хороший результат на обычном видео и
работает примерно **2 секунды на кадр 1080p** (при x2). Тяжёлые модели
`realesrgan-x4plus` / `realesrgan-x4plus-anime` дают максимум деталей, но
**14–46 секунд на кадр** — в десятки раз медленнее, поэтому имеет смысл только при x4.

**Клик по пресету возвращает все настройки ниже к его значениям по умолчанию.**
Любую настройку после этого можно менять вручную — выбор запомнится.

## Гибкие настройки (новое в v1.2)

Каждый параметр пресета можно переопределить вручную — программа запоминает
выбор в `ui_settings.json` и восстанавливает его при следующем запуске:

| Настройка | Варианты | Что делает |
|---|---|---|
| **Масштаб** | `x2` `x3` `x4` `4K авто` `8K авто` | x2: 1080p → 4K; x3: 1080p → ~5–6K; x4: 1080p → 8K. «Авто» сами подбирают масштаб под каждый файл так, чтобы результат был не ниже 4K/8K; если источник уже крупный — апскейл пропускается |
| **Модель** | `Авто` `Лёгкая` `Тяжёлая` | Лёгкая — быстро, тяжёлая — детальнее, но только при x4 (иначе автоматически берётся лёгкая) |
| **Плавность** | тумблер + `60 FPS` `120 FPS` | RIFE дорисовывает промежуточные кадры; можно отключить или задать целевую частоту кадров |
| **Тип видео** | `Обычное` `Аниме` | Для аниме выбирается своя модель — результат заметно лучше |
| **Кодировщик** | `Авто` `H.264` `H.265` `CPU` | GPU-кодирование AMD AMF (быстро) или CPU libx264 (медленнее, но выручает, если AMF сбоит) |
| **Качество** | `Авто` `Скорость` `Баланс` `Макс` | Насколько сильно жать итоговый файл: «Макс» — лучший поток, «Скорость» — файл меньше и кодируется быстрее |
| **Tile** | `Авто` `256` `384` `512` | Размер куска кадра, обрабатываемого за раз. Меньше — меньше видеопамяти (актуально для x4/8K); «Авто» сам поднимет tile до 384 при масштабе x3–x4 |
| **Экономить место** | тумблер | Промежуточные кадры пишутся в JPEG вместо PNG — экономит десятки гигабайт при почти той же качестве |

> Подсказки у каждого параметра — наведите мышь. Во время обработки выбор
> блокируется до конца работы.

## Скорость и место на диске

Ориентир для RX 570 на видео 1080p:

- **«Быстро»** — около **1 часа на 1 минуту видео 1080p** (лёгкая модель, без интерполяции);
- **«Баланс»** — около **1,5–2 часов** (лёгкая модель + плавность до 60 FPS);
- **x3** — примерно в 2 раза дольше x2 (кадров и пикселей больше);
- **«Максимально» (x4 → 8K)** — тяжёлая модель обрабатывает кадр 1080p за 14–46 секунд,
  поэтому минута видео может занять **десятки часов**. Программа показывает оценку
  времени перед началом и предупреждает, если ожидается больше 3 часов;
- во время апскейла и интерполяции в прогресс-баре видно, сколько осталось примерно;
- временные файлы могут занимать **от нескольких ГБ до десятков ГБ**
  (для 1 минуты 1080p → 4K-кадры это легко 20–40 ГБ, для 8K — заметно больше);
- итоговый файл — примерно как обычный HEVC/H.264 того же разрешения.

> Для длинных видео и для первых проб выбирайте «Баланс»: он в десятки раз быстрее
> «Максимально», а разница в качестве на обычном видео невелика.

Перед началом программа оценивает нужное место. Если его мало — спросит подтверждение.
Временная папка **`temp`** очищается автоматически после каждого видео и при отмене.

> Совет: если места впритык, включите «Экономить место» и обрабатывайте видео короткими частями.

## Отмена и закрытие

Кнопка **«Отмена»** останавливает текущее видео и убивает дочерние процессы
(FFmpeg / Real-ESRGAN / RIFE). Временные файлы удаляются.
При закрытии окна во время обработки программа спросит подтверждение.

## Если что-то пошло не так

> Полный журнал работы дублируется в текстовый файл: **`VideoBoost\logs\video_boost_*.log`**
> (хранятся 20 последних сессий). Если программа сообщила «Ошибка — подробности в журнале»,
> эти подробности есть и на экране (панель «Журнал» внизу окна), и в этом файле.

### «Не хватило видеопамяти» / `vkAllocateMemory` / `device lost`

У RX 570 всего 4 ГБ VRAM. Программа сама пробует уменьшить tile (256 → 192 → 128),
но если ошибка повторяется:

1. Выберите пресет **«Быстро»** (без интерполяции) или верните Tile в «Авто»/256.
2. Выключите «Повышать плавность».
3. Закройте браузер, игры и другие программы, использующие GPU.
4. Обновите драйвер AMD (Adrenalin).

### Ошибка Vulkan / «no device»

1. Обновите драйвер AMD Adrenalin для RX 570.
2. Убедитесь, что в системе есть `vulkan-1.dll` (обычно ставится с драйвером).
3. Перезагрузите компьютер.

### AMF-кодирование не работает

Это не смертельно: программа пишет в журнал предупреждение и автоматически
перекодирует через `libx264` (медленнее, но файл получится).
Если хочется AMF — обновите драйвер AMD и FFmpeg (кнопка «Скачать / проверить инструменты»
после удаления папки `tools\ffmpeg`). Можно также сразу выбрать кодировщик **CPU** вручную.

### Антивирус ругается на `ffmpeg.exe` / `rife-ncnn-vulkan.exe`

Это ложное срабатывание: файлы скачаны с официальных GitHub-релизов.
Добавьте папку `VideoBoost\tools` в исключения антивируса.

### «Не удалось скачать …»

Скорее всего, изменилась ссылка или нет доступа к GitHub. Программа покажет ссылки.
Скачайте вручную и распакуйте:

- **FFmpeg** — <https://github.com/BtbN/FFmpeg-Builds/releases/download/latest/ffmpeg-n9.0-latest-win64-gpl-9.0.zip>
- **Real-ESRGAN** — <https://github.com/xinntao/Real-ESRGAN/releases/download/v0.2.5.0/realesrgan-ncnn-vulkan-20220424-windows.zip>
- **RIFE** — <https://github.com/nihui/rife-ncnn-vulkan/releases/download/20221029/rife-ncnn-vulkan-20221029-windows.zip>

Как разложить вручную:

```
VideoBoost\
  tools\
    ffmpeg\
      ffmpeg.exe
      ffprobe.exe
    realesrgan\
      realesrgan-ncnn-vulkan.exe
      models\...
    rife\
      rife-ncnn-vulkan.exe
      rife-v4.6\...
```

Внутри архивов есть вложенные папки — можно распаковать целиком, программа сама найдёт
нужные `.exe` и модели рекурсивно.

### Видео обрабатывается, но итог выглядит «мыльно» или дёргается

- Для аниме выбирайте тип **«Аниме»**.
- Для сильно зашумлённого видео интерполяция может давать артефакты — попробуйте
  отключить плавность или сначала обработайте видео шумодавом.
- HDR-видео программа переводит в обычный SDR (особенность покадрового пайплайна).

## Требования

- Windows 10/11 x64
- Видеокарта с Vulkan (RX 570 подходит)
- Для 8K-результатов желательно монитор/плеер, понимающие 8K (файл всё равно будет 8K)
- Свободное место на диске: минимум 10 ГБ, желательно 30+ ГБ
- Интернет для первого запуска

**`VideoBoost.exe` не требует Python** — он собран со встроенным интерпретатором.
Запуск через `start.bat` — альтернативный вариант, для него нужен Python 3.10+
(проверить: `py -3 --version`), ставить ничего через `pip` не нужно.

---

## Как удалить

Просто удалите папку `VideoBoost` целиком. В системе ничего не остаётся:
реестр, `Program Files` и пользовательские папки не используются.

## Структура папки

```
VideoBoost\
  VideoBoost.exe            запуск двойным кликом (Python не нужен)
  video_boost.ico           иконка приложения
  start.bat                 альтернативный запуск через Python
  main.py                   интерфейс («жидкое стекло», гибкие настройки)
  engine.py                 обработка видео (масштаб/плавность/кодирование)
  requirements.txt          (пусто — внешних зависимостей нет)
  README_УСТАНОВКА.md       этот файл
  ui_settings.json          создаётся автоматически — запоминает пресет и все
                            гибкие настройки (масштаб, модель, FPS, кодировщик…)
  tools\                    создаётся автоматически
  temp\                     создаётся автоматически, чистится
  logs\                     создаётся автоматически — файлы журнала
                            (video_boost_*.log, хранятся 20 последних)
```
